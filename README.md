# pubstyle

Muted, colorblind-aware, minimalist figure style for papers (matplotlib + seaborn, LaTeX, Typst).

## Files
| File | Purpose |
|---|---|
| `pubstyle.py` | the style: palette, colormaps, rcParams, helpers (single file, copy next to your scripts or put on `PYTHONPATH`) |
| `pubstyle.mplstyle` | same rcParams as a plain style file (`plt.style.use("pubstyle.mplstyle")`; generated by `python pubstyle.py`) |
| `palette.tex` | xcolor colors (`pubIndigo` ...), pgfplots cycle list `pubcycle`, colormaps `pubseq` / `pubdiv` |
| `palette.typ` | Typst colors (`pub-indigo` ...), `pub-cycle`, gradients `pub-seq` / `pub-div` |
| `examples.py` | regenerates all example figures |

## Quick start
```python
import matplotlib.pyplot as plt
import pubstyle as ps

ps.use()                                   # ps.use(latex=True) for real TeX text (needs full TeX Live)
fig, ax = plt.subplots(figsize=ps.figsize("single"))   # 89 mm; also "onehalf" (120 mm), "double" (183 mm)
ax.plot(x, y, color=ps.C["indigo"])
ps.save(fig, "figure1")                    # figure1.pdf (vector, fonts embedded) + figure1.png (300 dpi)
```

## Palette (fixed order, never cycle)
indigo `#525A94`, clay `#D68A4E`, sage `#50B095`, rose `#B8566B`, periwinkle `#848DC8`,
ochre `#C9A53F`, sky `#6DBBE4`, grey `#868686` (neutral: "other", baselines).

* Use colors 1-4 whenever you can: they are safe in any combination (scatter, small multiples).
* Beyond 4 series, neighbours stay separable but non-neighbours may not: add markers (`ps.MARKERS`),
  linestyles (`ps.LINESTYLES`), hatches (`ps.HATCHES`) or direct labels.
* More than 7 categories: fold into "Other" (grey) or use small multiples.
* Sequential: `ps.SEQ` / `"pub_seq"` (light to dark indigo). Diverging: `ps.DIV` / `"pub_div"`
  (indigo - neutral - clay); pass `vmin=-m, vmax=m` or `center=0`.
* `ps.cvd(colors, "deutan" | "protan" | "tritan" | "gray")` simulates how a figure's colors look.

## Checks run on the palette (OKLab dE x100, Machado et al. 2009 CVD simulation)
* worst neighbouring pair under deuteranopia/protanopia: 9.8 (target >= 8)
* worst neighbouring pair, normal vision: 17.6 (floor 15); tritanopia >= 15
* colors 1-4: all pairs pass (worst 9.3 CVD, 15.8 normal)
* Deliberate trade-offs of "muted": chroma of a few hues sits just below 0.10 (OKLCH), and the lighter hues
  (clay, sage, ochre, sky) have 2-2.7:1 contrast on white. Use direct labels / markers for key distinctions.
* sage and grey look alike under red-green CVD (they are not neighbours): do not use both in one plot
  unless the grey is clearly "other" and labelled.

## LaTeX / Typst
* PDF output embeds TrueType fonts (pdf.fonttype 42): accepted by journals, text stays selectable.
* Include in LaTeX with `\includegraphics[width=\columnwidth]{figure1.pdf}`: figures are made at final size
  (7.5 pt base font), so do not rescale them.
* Typst: `#image("figure1.svg")` or the PDF/PNG; use `ps.save(fig, "figure1", formats=("svg",))` for SVG
  (glyphs are outlined, so it looks identical everywhere).
* Match your paper font: `ps.use(latex=True, latex_font="sans" | "serif")`, or change `ps._LATEX_PREAMBLE`.
